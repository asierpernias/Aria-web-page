# My web page for Aria's projects

This is the web page (WIP) that will serve as a display of all the work I have been doing for the YSWS from HackClub called Aria. For context I had to create music by programming with Strudel.cc a live coded music creator.

## Tracks

-**Phase Drift** - my first Strudel song, and actual song ever.
- **Mist** - an ambient piece.

## Built with

- HTML, CSS, and vanilla JavaScript, no framework was used for the web page.
- [Strudel.cc](https://strudel.cc) for the live-coded patterns embedded in each slide.

## Status

Work in progress. More tracks will be added as I keep working on the YSWS itself.
